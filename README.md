# java-calculator-precourse

## 📌 기능 구현 목록

### 👩‍💻프로그램 ```Application```
- 입력, 계산, 출력 3가지 과정을 연결한다.
- 위 과정에서 발생한 에러를 처리한다.
- ```StringCalculator```로부터 ```IllegalArgumentException```을 받을 경우 오류 메시지 출력 후 애플리케이션을 종료한다.


### ⌨️입력 ```CalculatorInput```
- 사용자로부터 문자열을 입력받는다.

### 🧮 계산 ```StringCalculator```
#### ✂️ 문자열 파싱 
- 입력된 문자열이 비어있을 경우 0을 반환한다.
- 커스텀 구분자 유무를 확인한다.
- 기본 구분자와 커스텀 구분자를 기준으로 문자열을 분리해 숫자 토큰을 추출한다.

#### 🔎 입력 유호성 검증
- 숫자 토큰들에 대해서 유효한 숫자인지 확인한다.
- 숫자 토큰이 유효하지 않을 경우 ```IllegalArgumentException```을 발생시킨다.

#### ➕ 덧셈 연산
- 검증된 숫자들의 덧셈 연산을 진행한다.

### 🖥️출력 ```CalculatorOutput```
- 연산 결과 도출된 값을 요구사항에 명시된 출력 형식에 맞게 출력한다.
- 출력 후 애플리케이션을 종료한다.
