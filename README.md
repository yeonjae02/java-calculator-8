# java-calculator-precourse

## 📌 기능 구현 목록

### 입력
- 사용자로부터 문자열을 입력받는다.
- 입력받는 문자열의 형식을 확인하고 사용자가 잘못된 값을 입력할 경우 ```IllegalArgumentException```을 발셍시킨다.
- ```IllegalArgumentException```이 발생하였을 경우 애플리케이션을 바로 종료한다.

### 계산
- 사용자가 입력한 문자열에서 구분자를 이용하여 각 숫자를 추출한다.
- 추출된 숫자를 이용하여 덧셈 연산을 진행한다.

### 출력
- 연산 결과 도출된 값을 요구사항에 명시된 출력 형식에 맞게 출력한다.
- 출력 후 애플리케이션을 종료한다.
